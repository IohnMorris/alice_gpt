# Alisa Voice — Мини 2: предварительная сборка

Это тестовая адаптация [Alisa Voice](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant). Сохранены история и авторство исходного проекта. На одной Мини 2 проверены установка с сохранением сессии, голос, микрофон, кнопка mute, подсветка и автозапуск после перезагрузки. Другие устройства и прошивки не проверены.

Для Windows 10/11 x64: скачайте `AlisaVoice-Mini2-browser-preview.zip`, распакуйте и откройте `AlisaVoice-Browser-Setup/Открыть установку.cmd`. Локальный мастер покажет подключение по SSH, установку и вход ChatGPT. Необходимы заранее полученный root и SSH; мастер не получает root автоматически. Вход ChatGPT происходит в отдельном окне браузера.

Для предварительной установки из PowerShell (после публикации в этом репозитории):

```powershell
irm https://raw.githubusercontent.com/IohnMorris/alice_gpt/main/install.ps1 | iex
```

Скрипт скачивает архив, проверяет SHA-256 и открывает локальный мастер. Исходник `install.ps1` доступен для просмотра перед запуском. **Это предварительная сборка**, не стабильный выпуск. Первая настройка нового устройства и нового аккаунта ещё не проверена. Голосовой клиент после установки работает на колонке без компьютера. После запуска нативной службы выполните `alisa native panel`: команда покажет локальный адрес вида `http://IP-колонки:2000/` и код сопряжения для тёмной панели на телефоне; компьютер для неё не нужен.

Не отправляйте никому пароль SSH, токены, профили браузера и резервные копии состояния. Подробности оригинального проекта см. в `README.md`; изменения Mini 2 находятся в исходниках репозитория.
