Установка голосового чата

Подключите колонку и войдите в ChatGPT. После установки голосовой чат работает без компьютера.

Готово к подключению

Установка работает на этом компьютере.

1. Подключение к колонке Ожидает

Нужна колонка с заранее полученными root и SSH. Пароль или приватный ключ вводится только в локальном мастере. Ключ должен быть уже разрешён на колонке; защищённые паролем ключи пока не поддерживаются.

2. Установка Ожидает

Проверим совместимость, сохраним существующие чаты и включим автозапуск.

3. Вход в ChatGPT Ожидает

Вход откроется в отдельном окне браузера. Пароль ChatGPT вводится только на сайте ChatGPT. «Вход сохранён» означает наличие сессии, её работоспособность проверяется в разговоре.

Уже настроено?

Можно проверить текущую установку без замены данных.

Страница работает только на этом компьютере. Получение root не выполняется автоматически.
