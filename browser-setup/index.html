Установка голосового чата

Подключите колонку и войдите в ChatGPT. После установки голосовой чат работает без компьютера.

Готово к подключению

Установка работает на этом компьютере.

1. Подключение к колонке

Нужна колонка с заранее полученными root и SSH. Пароль вводится только в локальном мастере.

2. Установка

Проверим совместимость, сохраним существующие чаты и включим автозапуск.

3. Вход в ChatGPT

Вход откроется в отдельном окне браузера. Пароль ChatGPT вводится только на сайте ChatGPT.

Уже настроено?

Можно проверить текущую установку без замены данных.

Страница работает только на этом компьютере. Получение root не выполняется автоматически.
