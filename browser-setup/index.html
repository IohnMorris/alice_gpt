1. Подключение к колонке
✓ Выполнено

Нужна колонка с заранее полученными root и SSH. Пароль или приватный ключ вводится только в локальном мастере. Пароль хранится в памяти мастера до его закрытия. Ключ должен быть уже разрешён на колонке; защищённые паролем ключи пока не поддерживаются.

ED25519 SHA256:9f4b2c8e11a7d04c5e8a33b91e2f0a1d7c6e4b2a (подтверждён)
Способ аутентификации SSH
Беспарольный вход для root@192.168.1.151 должен быть заранее разрешён в конфигурации SSH на колонке.
