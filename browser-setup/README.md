# Браузерный мастер установки — тестовая версия

Мастер работает только на `127.0.0.1:8769` компьютера. Для запуска Windows откройте `Открыть установку.cmd`; рядом должна лежать папка `AlisaVoice-Mini2-test`. Для установки требуется заранее полученный root и работающий SSH на колонке. Отпечаток SSH необходимо сверить с колонкой; пароль SSH не записывается в настройки. Вход ChatGPT открывается в отдельном окне и использует существующий механизм приложения.

Это не готовый релиз: нет проверенного bootstrap по GitHub, не проведена полная проверка первого входа и установки через мастер на чистом устройстве. Кнопка установки проверена на существующей конфигурации. Сервер управления на колонке не запущен, сайт при выключенном компьютере недоступен. Не публиковать комплект как законченный продукт.
